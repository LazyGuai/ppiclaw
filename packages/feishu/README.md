# @mariozechner/pi-feishu

Feishu/Lark channel adapter for pi.

This package provides a standalone Feishu bot runtime based on `@mariozechner/pi-channel-core`.

## OpenClaw Skills

Sync official OpenClaw Feishu skills (`feishu-doc`, `feishu-drive`, `feishu-perm`, `feishu-wiki`) into this project:

```bash
npm run sync:openclaw-skills --workspace @mariozechner/pi-feishu
```

Optional global install target:

```bash
npm run sync:openclaw-skills --workspace @mariozechner/pi-feishu -- --global
```
